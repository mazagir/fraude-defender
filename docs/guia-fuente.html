2 · Inicio rápido: registrarse e iniciar sesión

Crear cuenta:

  1. Abre la app web y pulsa «Registrarse» / «Comenzar».
  2. Completa: Nombre, Correo electrónico válido y Contraseña segura.
  3. Pulsa Crear cuenta. Recibirás respuesta inmediata del servidor (201). Si algo fallara durante el renderizado, la app muestra una pantalla de recuperación con botón «Recargar aplicación» en vez de quedarse en blanco.

Iniciar sesión:

  1. Introduce tu correo y contraseña.
  2. Si tienes MFA activado, se pedirá el código TOTP de 6 dígitos de tu app autenticadora.
  3. La sesión queda guardada en el navegador (aegis_token) — no necesitas volver a entrar.

⚠ Límites anti-abuso: registro 5/min · login 10/min · análisis IA 20/min por IP.

Consulta el motor sin abrir la app: envía el mensaje sospechoso por WhatsApp y recibe el análisis al instante.

6 · Arquitectura del despliegue

Frontend → Vercel

React 19 + Vite + Tailwind 4.
Auto-deploy desde main.
Variables: VITE_API_URL, VITE_POSTHOG_KEY (opcional).

Backend → Render

FastAPI + Docker (free, Oregon).
Servicio: agishield-api.
Healthcheck: /health.
Rate limit global 200 req/min.
Webhook Twilio opt-in.

Datos → Supabase

PostgreSQL 17 (pooler, sa-east-1).
Tablas: users, fraud_reports, scan_history.
Migración automática al arrancar.

🤖 Bot Keep-Alive (GitHub Actions): cada 10 minutos consulta /health, el listado público y /threat-intel para que ni Render ni Supabase entren en pausa por inactividad.

7 · Solución de problemas

SíntomaSolución
No llega código MFAMFA usa TOTP offline. Verifica que la hora del teléfono esté sincronizada.
Workflow Keep-Alive deshabilitadoGitHub pausa cron tras 60 días sin commits: Actions → re-habilitar manualmente.
El bot no responde en WhatsAppVerifica que te uniste al sandbox de Twilio y que el webhook apunte a /api/v1/webhooks/whatsapp.
Pantalla de recuperación tras un errorPulsa «Recargar aplicación». Si persiste, borra caché (Ctrl+F5); tus datos no se pierden.
